# Unity Pathfinding Project

This repository contains the skeleton of a Unity 2022 LTS project for a 3‑D shortest‑path demo with weighted A* and dynamic NavMesh.

## Folder layout (relative to the project root)
```
Assets/
 ├─ Scripts/               # C# source files
 │   ├─ GridManager.cs
 │   ├─ Tile.cs
 │   ├─ WeightedAStar.cs
 │   ├─ PriorityQueue.cs
 │   ├─ NavMeshHelper.cs
 │   ├─ AgentManager.cs
 │   ├─ LevelEditor.cs
 │   ├─ UIManager.cs
 │   ├─ BenchmarkRunner.cs
 │   └─ MapSerializer.cs
 ├─ Prefabs/               # Prefabs (Tile, Knight, Wizard)
 ├─ Materials/             # Materials and shaders
 └─ Scenes/                # Main.unity, Demo.unity
```

The actual Unity project files (`*.unityproj`, `Packages/manifest.json`, etc.) are not stored in the repository because they are generated by Unity when you open the folder.

## Getting started
1. Install **Unity 2022 LTS** with the **Universal Render Pipeline (URP)** template.
2. Clone or copy this folder to `c:\Users\tranm\OneDrive\Máy tính\cấu trúc giải thuật\UnityPathfindingProject`.
3. Open Unity Hub → **Add** → select the folder → create a new project using the **URP** template.
4. Once Unity loads, create a new empty scene **Assets/Scenes/Main.unity**.
5. Add a **NavMeshSurface** component to an empty GameObject called `NavMeshRoot` and bake the NavMesh (Window → AI → Navigation).
6. Drag the provided scripts into **Assets/Scripts**. The scripts are self‑contained and compile automatically.
7. Create a **Tile prefab** (cube) and attach `Tile.cs` and a **NavMeshModifierVolume** (area = 3 for forest, 10 for water, etc.).
8. Use the `LevelEditor.cs` component on a controller object to paint terrain and trigger NavMesh rebakes.
9. Press Play – you should see agents navigate using the custom WeightedAStar implementation.
